XeraX SDR — Windows community preview

For Windows 10/11, 64-bit. Connect a compatible SDR or use an RTL-TCP server.
Choose your speakers in Windows sound settings before starting reception.
The app must remain open while listening.

Core decoding, scanning, replay and English/Spanish controls are included.
Optional OpenAI / DeepSeek reception investigations use your own API key.
AI reviews measurements; it does not accelerate radio decoding. API charges apply.
Direct HackRF USB and extra receiver workers are not included in this preview.
Physical receiver validation is still pending.

This installer does not change USB drivers or firewall settings.
See START-HERE.txt in the application folder for setup and feature details.
