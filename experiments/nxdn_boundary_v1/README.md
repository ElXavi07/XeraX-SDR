# Bounded NXDN relaxed-sync experiment

Isolated, single-receiver discriminator study. No app target or default links
this policy. Registration precedes input generation and native execution:
[fixed hypothesis and gates](../../docs/research/NXDN-BOUNDARY-V1-PREREGISTRATION-2026-09-25.md).

After a real complete proven frame, the candidate temporarily declines eight
noncanonical sync patterns outside three expected windows. Exact sync patterns
remain unrestricted. Both executables retain level updates, normal two-hit
acquisition, FEC, channel checks and audio routing. The baseline performs the
same private bookkeeping with the veto disabled. An off-phase relaxed-sync
control deliberately tests the plausible loss of a previously decodable frame.

`prepare.py` copies sixteen frozen waveforms and independently constructs two
pre-shaped gap controls. It refuses an existing output directory. `prepare_build.py`
binds product bytes to commit56e83dd and layers a private matcher and frame-context
sidecar over the unchanged observation-v2 instrumentation. CMake links real
DSP/protocol/engine/vocoder implementations with playback disabled. The original
DSP archive must not supply its matcher object; inspect both maps before replay.

`phase_policy.c` has no receiver or source-truth dependency. `phase_runtime.c`
adapts actual state for one receiver. Production multireceiver ownership and
hidden configuration/epoch transitions need separate engineering. Separate
logs cross-check contexts, decisions, proof and actual symbol counters; generation
and owner identity remain this fixed provider's limited test domain.

`analyze.py` hash-binds the frozen observation-v2 checker, validates newly admitted
transforms separately, and distinguishes measurement failures from decoder
retention failures. `run.py` freezes inputs, binaries, build records, scripts and
archived anchors before144 new processes, each once. Every exit, timeout and
exception remains recorded. It refuses to overwrite earlier results. Do not
rerun the earlier216-case recovery or36-case observation matrices.

Framework checks:

```text
python -m unittest discover -s experiments/nxdn_boundary_v1 -v
python -O -m unittest discover -s experiments/nxdn_boundary_v1 -v
```

The CMake `xerax_nxdn_boundary_policy_test` target uses explicit checks under
optimization. These checks do not establish receiver success. A measurement
pass also does not override any loss of baseline-correct content. No speed,
legitimate speech, encrypted traffic, complex-IQ, RF, phone or GPU claim follows
from this screen. Independent clear voice fixtures and impaired IQ/device tests
remain prerequisites for product promotion.
