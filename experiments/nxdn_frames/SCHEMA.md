# Native observation schema 2

CLI: `xerax_nxdn_frame_observer <vector directory> <existing output directory>`.
Numeric input files are valid.dibits, wrong_all_crc.dibits, wrong_lich.dibits.
JSONL stdout: three direct rows,156case rows,one terminal summary. CRC enums
SACCH1,FACCH1=2. No original-IQ or PCM measurement.

Direct row: `{schema:2,kind:"direct",variant:"valid"|"wrong_all_crc"|"wrong_lich",
events:[CRC,...],errors:int,original_iq_samples:null,pcm_latency:null}`.
Direct CRC events use frame_call=-1,consumed_end=0,pop_count=0; this tests channel
blocks without sync or LICH gating. Always three events, including wrong_lich.

Case row: `{schema:2,kind:"case",id:"valid-r8-o0-c1",scenario:string,ramp:8|14,
offset:0..19,chunk:1|37|512,domain:"discriminator_samples",rate_hz:48000,
waveform_samples:16640,pop_trace:"<id>.u32le",baseline:RUN,observed:RUN,
original_iq_samples:null,pcm_latency:null}`.
Scenario valid uses2ramps×20offsets×3chunks=120cases. Six scenarios bad_crc,
bad_lich,mixed,one_fsw,zero,random use2ramps×offset0×3chunks=36cases.

RUN: `{frames:[FRAME,...],events:[CRC,...],dispatches:[DISPATCH,...],
voice_requests:int,other_side_effects:int,errors:int,pop_count:int,
skipped_samples:int,lineage_errors:int,source_frontier:int,exhausted:0|1}`.
Max16frames,48CRCevents,64dispatches. Baseline disables both observers, so its
events list is empty and pop_count,skipped_samples,lineage_errors,source_frontier
are zero. Actual common decoder/dispatch fields must equal the observed run.

FRAME: `{sync_code:int,provider_sync:int,cache_sync_pos:int,cache_sync_len:int,
provider_end:int,cache_end_pos:int,cache_end_len:int,result:0|1|2,confirmed:0|1,
last_sync:int,dispatch_begin:int,dispatch_end:int,voice_after:int,source_truncated:0|1,
crc_begin:int,crc_end:int,sync_consumed:int|null,end_consumed:int|null,
pop_sync:int,pop_end:int}`.
Both NXDN positive28 and inverted29 syncs are passed to nxdn_frame. The frame list contains accepted
syncs/frame invocations; unsuccessful search returns are reflected by exhausted
state, not manufactured frames. Baseline crc_begin/crc_end/pop_sync/pop_end are0;
consumed fields null. Other FRAME fields compare exactly between baseline/observed.
CRC index intervals are half-open and identify the events generated by this
invocation. Dispatch intervals are similarly half-open. A frame returning1 can
be historically confirmed while invalid now; only result2 is current proof.
source_truncated records EOF reached during that frame's body. Such results
remain visible but cannot count as fully supplied successful frames; a result2
under truncation fails the receiver gate with an explicit censoring reason.

CRC: `{frame_call:int,channel:1|2,part:0|1|2,computed:int,received:int,
soft_pass:0|1,fallback:0|1,bits:string,consumed_end:int,pop_count:int}`.
SACCH has26bits/CRC6/part0. FACCH has80bits/CRC12 and part1/2. Direct controls
call both halves with parts1and2. Event verdict is computed==received. Validate
computed against independent CRC of the actual reported bits even on negatives.
Callbacks occur after the whole body has been read. Compare event frontier with
its enclosing frame end, not a fictional earlier SACCH execution position.

DISPATCH: `{bits:string,length:int}`, length0..512, actual copied downstream
content request; semantic routing is replaced by a capture sink. It is a parity
observation, not a declaration that every dispatch request has a valid fullframe.

Summary: `{schema:2,kind:"summary",cases:156,direct_cases:3,failures:int,
domain:"discriminator_samples",rate_hz:48000,original_iq_samples:null,
pcm_latency:null}`. Failures are infrastructure/bounds/parity failures. Receiver
quality gates are analyzed separately and may fail without corrupt measurements.

Raw pop files contain every successful supplied-sample index, little-endian u32.
Each frame's pop_sync/end locate its exclusive source frontiers. Indices strictly
increase within[offset,16640), reconcile gaps and finalfrontier. Finite input
is32alternating preamble +4frames +32zero-dibitpositiveguard. Scenario mixed
usesvalid,valid,wrong_all_crc,wrong_lich. one_fsw replaces everything after the
first fullFSW with zero dibits;zero replaces all float samples with0;random uses
xorshift32 seed0x413288FB shifts13/17/5 top2bits over all832dibits.

Measurement contract requires complete schema/grid, correct direct blocks,
lineage, event association, bounded content and disabled/enabled common parity.
Receiver gate additionally requires ≥1true-boundary full good frame per positive
case and no false currentproof. True generated-frame proof requires positive28;
inverted29 accepts remain observable controls and cannot establish positive-frame
truth even at a coincident landmark. True syncend tolerance±20samples around
640+3840*frame+200 (four actual source frame ordinals0..3). Expected variant
comes from scenario/sourceordinal, never payload search. A true accepted badLICH
must have zeroCRCevents/result!=2. BadCRC finalchannels must fail. Mixed source
frames0/1 may validate;2/3 may not. All nonprotocol/currentfalseframe proofs fail
the receiver gate. Preserve counts and summaries of off-boundary sync/CRC events.

Schema1 from the first run is frozen separately. It rejected all nonpositive
accepts before recording them and therefore failed to exhaust six random cases.
Schema2 records both NXDN polarities without changing input vectors or receiver
code. The native unsupported-sync diagnostic now includes the actual value.
