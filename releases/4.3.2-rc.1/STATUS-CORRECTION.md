# Release-status clarification

Both **4.3.1** and **4.3.2-rc.1** are marked as **prereleases** on GitHub.
4.3.1 is the unchanged comparison baseline for this research, not a final stable
release. Physical receiver/phone and human-listening acceptance remain pending.

The initial source archive, verification JSON, research notes and PR description
called 4.3.1 "stable." That wording was inaccurate. Read it as "comparison
baseline / previous prerelease." Current notes have been corrected; the original
checksummed artifacts are retained rather than silently replaced. This correction
does not change any APK, Windows binary, test count, experiment result or checksum.

The initial seven release assets were verified against GitHub's SHA-256 digests.
This clarification is an additional documentation asset.
